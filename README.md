# time-Homework-Tracker <br>
# How To Use <br>
Step 1: Save the Code

Copy the entire Python code from GitHub.

Open Notepad on your laptop.

Paste the code inside Notepad.

Click on File > Save As.

Type the file name exactly like this: timetable.py

Below the name, change "Save as type" to "All Files".

Save it to your Desktop so it is easy to find.

Step 2: Open the App

Go to your Desktop.

If you use VS Code for your coding practicals, you can simply open the file there and click the Play (▶️) button on the top right.

Alternatively, you can just right-click on timetable.py, select Open with, and choose Python.

Phase 2: How to Use

1. Manage Your Schedule

You will see a default timetable on the screen.

Click on any time or task text to edit it. You can change it to match your college lecture timings or group project meetings.

The code will automatically show a red LIVE badge next to the task you should be doing right now based on the clock.

2. Track Your Doubts and Homework

Select a subject from the dropdown menu (like C#, Java, python, or react js).

Type your question or homework topic in the box and click Add.

When you finally understand the topic or finish the homework, click the ✔ Solved button to remove it from the list.

3. Add Normal Tasks

Use the bottom right section to add simple reminders, survey notes, or general assignments.

Click ✔ Done when you finish them.

4. Change Themes

Click the 🌓 Theme button at the top to switch between Light mode and Dark mode to protect your eyes while studying at night.

5. Save Your Data

Click the 📤 Export Data button at the top to save all your tasks and timetable in a secure file on your laptop.

If you ever open the code on another laptop, just click 📥 Import Data and select that file to load everything back!
